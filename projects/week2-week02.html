THE IDEA BEHIND THE INTERACTION

How it works.

  1. 01

    Read two strings

    The dog's name and favorite number both arrive as text.

  2. 02

    Repeat the number text

    Multiplying the original string by three repeats it.

  3. 03

    Make a numeric copy

    float() creates a numeric version for the final sentences.
