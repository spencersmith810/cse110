THE IDEA BEHIND THE INTERACTION

How it works.

  1. 01

    Start with blanks

    A for loop creates one underscore for each secret letter.

  2. 02

    Check every guess

    A while loop continues until the guess matches. Every attempt is counted, including wrong lengths.

  3. 03

    Build a hint

    Uppercase means an exact position; lowercase means the letter is elsewhere; an underscore means absent.

LOOK CLOSER / LINE 28for index in range(len(secret_word)):

The index lets the program compare the same position in both words before checking membership anywhere in the secret.
